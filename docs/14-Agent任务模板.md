# 14 — 可直接复制给 Codex / OpenCode / Claude Code 的任务指令

以下模板可直接复制给根 Agent。它们是**任务声明**，不替代真实项目的 AGENTS、技术锁、CI。

## 模板 A：在私有 GitHub RMDL 主仓库继续建设

```text
你在 remmai-design-system 私有仓库中工作。首先读取根 AGENTS.md、RMDL.md 和 docs/06~13 中与本任务相关的文件。不得跳过或修改既有架构红线。

目标：将现有 RMDL v0.3 的 packages/ui 与 packages/tokens 升级成可以通过 GitHub Packages 私有发布的正式 npm 包。先审计，不要假设已可发布。

必须：
1. 报告现有包中的 private:true、源码 exports、缺失构建/类型声明/真实 Consumer 测试等事实。
2. 先提选型和分期计划（构建器、workspace、发布工具、包名 scope 需要我确认）；不要自行把 GitHub Owner 当成 remmai。
3. 我确认后完成发布工程、类型声明、Demo、视觉/行为测试、Release CI。
4. 不得发布正式包、创建 Release、更新 approved Registry，除非我明确批准。
5. 最终输出实际 PASS/FAIL/NOT RUN、改动清单和安全注意事项。
```

## 模板 B：从 A 项目提炼表格，给 B 项目使用

```text
任务：A 项目的表格已经被我认可，请把它提名为 RMDL 公共 DataTable，并规划 B 项目的复用。

必须先检查 A 中真实表格源码、截图和业务耦合；只读检查 RMDL Registry、packages/ui 现有能力；不要重复创建另一个表格框架。

第一阶段只提交提案：需要移除的业务依赖、稳定 Props/API、受控视觉约束、空/加载/错误/分页/响应式/深浅色/键盘行为、测试、发布版本计划。

未经我批准不得修改 Registry 为 approved，不得发布 npm 包，也不得擅自修改 B 项目或覆盖截图基线。等我认可提案，再按 UI Maintainer 的独立写权限完成实现和 PR。
```

## 模板 C：初始化一个新业务项目

```text
请按照 RMDL 标准初始化我的新项目。先读取根 AGENTS.md、vendor/rmdl/RMDL.md、vendor/rmdl/docs/01-选型与审批协议.md。

你必须先提供一个精简且有默认建议的技术选型问答，重点让我选择：产品类型、后端语言、ORM、数据库、认证、部署方式；Web 前端遵守 RMDL 强制规则，不得另选一套样式/组件库。

在我明确确认之前，只允许创建选型草稿/计划，不允许初始化业务脚手架或安装依赖。确认后生成锁定配置、按 RMDL 页面契约实现，并运行真实工程检查与视觉测试。
```

## 模板 D：重构一个现存后台

```text
先审计现有前端 UI 与 RMDL 的差异，按功能优先级提出渐进式改造计划。不要直接大规模换框架，不要降低业务功能，不要凭空创造页面结构。

如果已存在发布的 RMDL UI 组件，必须固定版本复用；找不到的组件列为候选提案，不得私自在项目中复制公共组件源码形成新分叉。

给我展示：保留项、替换项、影响页面、迁移顺序、风险、回滚、需要批准的选项和验收截图清单。我批准后才能实施破坏性迁移。
```

## 模板 E：前端业务页面开发（纯净工作台 / 防 AI 废话专属）

派发具体业务界面开发（如新增用户列表、监控看板、告警配置）时直接附带：

```text
任务：实现 [功能名称/页面路由] 界面。

执行约束：
1. 遵守 RMDL 页面契约（vendor/rmdl/docs/02-前端视觉与页面契约.md）与已发布的组件规范。
2. 纯净工作台原则（Zero-Slop Rule）：本页面为专业高密度控制台，严禁在底部、侧边或留白区域生成“功能介绍”、“核心特性”、“使用指南”、“本模块提供以下能力”等回显本提示词的宣讲式卡片、特性网格或说明书。
3. 容器白名单：只允许出现 3 类操作容器——筛选工具栏 (Toolbar/Filter)、核心数据工作区 (Table/Form/Board)、底栏操作/分页区 (Pagination/Footer)。
4. 文案边界：只允许操作按钮文本（简明动词 ≤4 字）、输入框 placeholder、复杂字段右侧小问号 Tooltip。严禁为了凑版面堆叠大段文字。
5. 交付验收：写完必须在项目根目录运行 `bun vendor/rmdl/scripts/rmdl.mjs check --root .` 确保静态门禁全绿，并通过本地 typecheck 与 build。
```
