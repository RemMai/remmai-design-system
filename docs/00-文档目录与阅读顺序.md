## 推荐实际执行顺序（不是章节编号）

**首次搭建私有 RMDL 主仓库**：09 → 06 → 12 → 13 → 14。

**新项目初始化**：06 → 01 → 02 → 10 → 03 → 11。

**A 项目表格共享给 B 项目**：02 → 07 → 08 → 10 → 11 → 12。

**旧项目规范化重构**：06 → 04 → 01 → 02 → 03 → 10 → 11。

以上顺序只是阅读和操作导航，不影响 `AGENTS.md`、`RMDL.md` 中的强制规则及审批要求。

## 文件更新规则

- 已有文档的编号保持稳定；不要仅为调整阅读次序而重命名文件，否则还需修改仓库内所有相对链接和 Agent 引用。
- 新增独立主题时使用下一个连续编号（如 `15-...md`）；不要故意留空编号。
- 重新组织阅读路线，优先更新本文和根目录 `README.md`，不要重排历史编号。
- `CODEOWNERS.example`、`ADR-template.md` 等无编号的文件属于模板/示例，并非缺失章节。
